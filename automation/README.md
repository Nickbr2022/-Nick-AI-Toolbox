# Automation

Ferramentas e referências para automatizar tarefas, integrações e workflows.

## Seleção

### n8n
https://github.com/n8n-io/n8n

Uso: automações com APIs, mensageria, planilhas, bancos de dados, IA, relatórios e processos de negócio.

### n8n-workflows
https://github.com/Zie619/n8n-workflows

Uso: biblioteca de workflows de referência para acelerar implementações.

## Critério
Priorizar automações reutilizáveis, auditáveis e fáceis de manter.
