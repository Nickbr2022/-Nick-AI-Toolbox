# Nick AI Toolbox

Hub pessoal organizado para IA, automação, trading, criação visual, APIs e skills.

## Estrutura

- `skills/` — skills pessoais revisadas e endurecidas
- `ai-agents/` — frameworks e ferramentas para agentes de IA
- `automation/` — automação de processos e workflows
- `trading-markets/` — ferramentas de IA para mercados e trading
- `creative-ai/` — geração e edição visual com IA
- `apis-data/` — APIs, dados e fontes úteis
- `reference/` — materiais de referência que merecem ser mantidos

Manter apenas projetos com utilidade prática. Evitar duplicados, forks sem propósito, repositórios abandonados e ferramentas que não agreguem ao uso atual.
